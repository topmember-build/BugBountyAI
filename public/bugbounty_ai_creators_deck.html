Security
Security, Trust & Compliance
BugBountyAI
Auth0 + Supabase Dual Auth

Enterprise-grade auth with JWT session management, automatic token refresh, and middleware session syncing across all API routes.

Row-Level Security (RLS)

Every database table enforces user-scoped RLS policies. Users can only access their own audits and findings. Zero data leakage risk.

Re-entrancy Protected Contracts

BugBountyEscrow.sol uses OpenZeppelin’s ReentrancyGuard and SafeERC20 on all state-mutating functions. Single-use audit ID prevents replay.

Multi-Provider RPC Failover

Primary Thirdweb Gateway with automatic fallback to Arc public RPC. Gas balance diagnostics prevent stuck transactions.

API Security Hardening

CORS protection, input validation, rate limiting on sensitive endpoints, and sanitized repository URL processing across all 25+ API endpoints.
